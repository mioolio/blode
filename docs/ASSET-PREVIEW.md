# 资源预览

在项目资源中点击文件，即可在工作区打开。图片、音频、视频与源码共用标签页；其他二进制文件显示文件属性和十六进制摘要。

## 使用

| 类型           | 操作                                            |
| -------------- | ----------------------------------------------- |
| 图片           | 适应窗口、原始尺寸、放大、缩小；显示像素尺寸    |
| 音频           | 播放、暂停、拖动进度、调整音量；显示时长        |
| 视频           | 播放、暂停、拖动进度；使用原生播放器控件        |
| 其他二进制文件 | 查看大小、类型、修改时间和前 4 KiB 十六进制内容 |

单击文件替换当前预览标签；双击文件或标签可固定。Ctrl+S 也可保留当前标签。关闭标签、切换文件或关闭工程时停止对应播放器，返回标签后可重新播放。

常见图片类型包括 PNG、JPEG、GIF、BMP、ICO、WebP 和 AVIF；音视频使用宿主浏览器支持的解码器。SVG 保留源码编辑方式。图片加载失败或媒体解码失败时，可在当前预览中重新加载。

外部修改资源后，工作区按文件大小及修改时间更新预览。普通状态刷新不打断正在播放的媒体。

## 桌面与 Web

桌面版通过 `blode-asset` 协议读取当前工程资源；Web 版从运行 Blode 服务的目标电脑读取文件。媒体按需加载，支持 Range 分段读取和进度跳转。

工程快照只保存文本内容和资源目录信息，音视频数据通过独立流读取。资源地址绑定当前工程与具体文件；切换工程后重新获取地址。

## 协作与自动化

资源标签同步到其他协作成员，并显示查看用户。媒体查看状态使用文件级标记，文本编辑仍走已有的草稿、合并与撤销流程。

外部 AI 可用 `project.asset` 读取资源描述，再通过 `ui.command` 打开对应文件。参数和工具名见 [AI 接口](AI-PIPE.md)。

```json
{
  "expectedProjectRoot": "C:\\work\\project",
  "path": "assets/photo.png"
}
```

# 桌面托盘

桌面端启动后创建 Blode Studio 托盘图标。

| 操作                            | 行为                         |
| ------------------------------- | ---------------------------- |
| 点击窗口右上角关闭，或按 Alt+F4 | 默认隐藏主窗口，程序留在托盘 |
| 单击或双击托盘图标              | 恢复主窗口；已最小化时先恢复 |
| 托盘菜单 → 显示 Blode Studio    | 恢复主窗口                   |
| 托盘菜单 → 退出                 | 结束程序                     |
| 文件 → 退出                     | 结束程序                     |

隐藏到托盘保留当前项目与未保存草稿。真正退出时，有修改会出现“保存并退出／放弃并退出／取消”；没有修改则直接结束。

关闭行为保存在用户数据目录的 `desktop-lifecycle.json`：

```json
{ "version": 1, "closeToTray": true, "locale": "zh-CN" }
```

开发版默认位置是 `.tools/dev-user-data/desktop-lifecycle.json`。设为 `false` 时，右上角关闭也进入退出流程；托盘菜单在窗口打开期间仍可使用。主进程修改后重启开发版生效。

独立硬件调试窗口、扩展窗口仍由各自关闭按钮关闭。Web 页面不会通过“文件 → 退出”关闭宿主服务。开发模式下，启动命令进程仍负责整个开发会话。

# 桌面工作台新功能

本文说明本轮桌面端改动。涉及主进程、串口和调试器的更新，需要退出并重新启动开发版才能完整生效。

## 最新内部工作台更新

- **终端 → 命令窗口** 使用持久 PowerShell／PTY，支持交互输入、中文、命令历史、补全、缩放与中断。
- 插件通过 `ui.views` 注册独立窗口和底部面板，桌面打开窗口，浏览器请求新标签。
- 退出未保存工程提供保存、放弃、取消；首选项可启用关闭到托盘。
- 后台与失焦状态隐藏阅读标记，回到前台先同步文件，再恢复光标与视口。
- 硬件调试和首选项减少重复说明，安装详情按需查看，统一控件与设备栏滚动。

依赖升级、完整用法及验收清单见[工作台交互更新](internal/workbench-interaction.md)。这些内部预览更新已合入 `main`，尚未进入现有 0.2.3.6 发行包。

## 代码导航、语言规则与独立 Git

- C/C++ 支持右键与 F12 跳转定义、查看声明与引用，头文件路径可直接打开；多个结果通过编辑器候选列表切换，Alt+← 返回。
- 工作区符号按文件内容增量更新，保存源码的缓存写入 `.blode/index`；函数、宏、类型和变量参与补全。
- C99／C11／C17／C23 使用独立 JSON 目录，函数按字母分文件，关键词、代码片段与源码规则独立维护；工程可通过 `languages/C/<标准>/` 自定义。见 [语言规则](LANGUAGE-RULES.md)。
- 右键工程根目录的 `be` 打开高级设置，以表单编辑名称、平台、编译入口、文件清单和 C 标准，并预览 JSON。
- Git 默认管理本软件的 `.blode/git`，可停用或移除独立历史；共享已有 `.git` 需要主动开启，删除共享历史有单独目标确认。见 [Git](GIT.md)。
- 目标设备、资源统计、串口和调试器文案精简，移除重复说明，保留操作状态与实际错误。

## 启动与加载响应

- 开发启动共享一次进程查询；先检查 Electron/esbuild 权限再构建，避免每次递归 SDK。完整工具检查保留在安装及手动权限修复中。
- Vite 只扫描主页面入口，忽略工具和产物目录。启动日志逐项输出耗时，长等待每 5 秒报告当前阶段；`npm run dev -- --diagnose-startup` 可用独立缓存和端口检查准备流程。
- 窗口先显示主题首屏，服务并行初始化；设备与工具链首次检查在后台完成，期间显示检查状态。
- 编辑器、首选项、资源布局、AI 与硬件调试按需加载，移除全局重复的 Monaco 样式；编辑器准备期间可先阅读当前源码。
- 不承诺固定启动秒数；首次依赖预构建、磁盘速度和系统驱动均会影响耗时，诊断方法见 [开发约定](DEVELOPMENT.md)。

## 本轮协作与工程管理升级

- 网页撤销／重做仅作用于自己的编辑，全局撤销限本地桌面；重叠修改会明确提示。共享标签不抢焦点，协作者头像堆叠，远端修改保留阅读锚点。见 [协作](COLLABORATION.md)。
- 文件树显示 Git M／U 等状态，图形化管理差异、暂存、提交、分支、远端和本地身份；沿用目标电脑已有 Git 与凭据。命令面板仍可执行明确命令。见 [Git](GIT.md)。
- 工程可导出可迁移 ZIP，收集外部依赖并改写副本配置。见 [工程分享](PROJECT-PACKAGING.md)。
- 首选项采用宽矩形和左右导航，支持工具并行版本及自定义路径。见 [工具版本](TOOL-VERSIONS.md)。
- 新增独立 Node Web 版；文件选择指向目标电脑，窄屏可切换文件、编辑器与设备区域。见 [Web 服务](WEB-HOST.md)。
- DOMPurify 锁定至 3.4.17；完整 [平台支持](PLATFORM-SUPPORT.md) 与 [路线图](ROADMAP.md) 区分实现状态和实际验证范围。

## 首页与工程切换

- 首页显示最近打开的工程，可直接重新打开；移除记录只清除历史，不删除工程文件。
- 工作时可返回首页，再回到当前工程；也可保存并关闭工程回到首页，应用保持运行。
- 没有正在工作的工程时隐藏项目资源面板。
- 目标设备面板右上角的叉号可关闭面板，从“视图”菜单可重新显示。
- 点击首选项直接打开统一设置界面。

## 标签与编译入口

只查看文件时使用预览标签，打开另一文件会替换预览。修改内容或按 `Ctrl+S` 后固定标签；固定标签会保留到下次恢复工程。标签过多时支持横向滚动，并将当前标签滚动到可见位置。

未保存标签关闭时提供“保存并关闭／不保存并关闭／取消”；保存只处理当前文件，失败或途中出现新修改会保留标签。共享标签也能在当前窗口关闭，不会因为另一位用户仍在阅读就立即重现。已同步协作内容在“不保存并关闭”后继续保留给其他协作者。页面离开、刷新和最后一个编辑标签关闭时会清理阅读状态，迟到消息不能复活旧用户。详见 [协作与标签生命周期](COLLABORATION.md)。

桌面与网页会同步文件、资源布局和 AI 自动化标签，包括只有工具标签的窗口；新标签不会抢走对方当前页面。源码阅读标记增加平滑移动、伸缩、淡入淡出，并在本地滚动时立即对齐。系统减少动画设置会关闭这些过渡。

在项目资源中右键文件或文件夹，设置为编译入口。配置写入工程根目录的 `be`，设置入口不会立即开始编译。STM32 的 `main.c` 仍需要配套启动文件、链接布局和依赖；仅有一个 C 文件不足以描述完整单片机工程。

编译无需连接硬件。先确定 ESP32-S3 或 STM32 编译平台；受支持的 STM32 Keil 工程可利用 `.uvprojx` 信息自动确定编译配置及参与构建的文件。无法唯一确定平台时需要手动选择。烧录与目标识别仍需要真实连接。

## 固件导出与无工程烧录

从“运行”菜单打开固件工具：

| 操作         | 格式与用途                                       |
| ------------ | ------------------------------------------------ |
| 导出固件     | BIN、Intel HEX、S-record；STM32 另可导出对应 ELF |
| 烧录已有固件 | BIN、Intel HEX、S-record，无需打开工程           |

导出依赖有效的构建记录和匹配的产物。ESP32-S3 导出会整合实际启动、分区和应用镜像；HEX／S-record 保留地址，BIN 的地址信息由伴随说明文件记录。

无工程烧录时，选择文件、平台与连接设备；BIN 需要核对装载地址，HEX／S-record 使用文件中的地址。确认目标与写入范围后才能执行。ELF 在这里用于 STM32 导出或调试符号，不作为独立烧录文件导入格式。

## 串口通信与设备更新

在底部串口面板选择 COM 端口及波特率后连接。支持 UTF-8／HEX 收发、无换行／CR／LF／CRLF，以及高级选项：

| 参数   | 可选值                         |
| ------ | ------------------------------ |
| 波特率 | 常用值或自定义，110～4,000,000 |
| 数据位 | 5、6、7、8                     |
| 校验   | 无、奇、偶、Mark、Space        |
| 停止位 | 1、1.5、2                      |
| 流控   | 无、RTS/CTS、XON/XOFF          |

具体组合需要串口设备及驱动支持。UART／VCP 串口与 SWD 调试探针是不同连接；ST-Link 没有提供 VCP 时，不会因此出现在 COM 列表中。

设备在首次初始化时枚举，后续界面读取缓存。手动点击刷新可重新枚举；Windows 设备变更通知也会触发防抖更新。工具操作或调试会话占用硬件时，自动扫描延后执行。枚举失败时保留上次信息；确认设备移除后清除失效选择，回到连接器占位选项。

## 独立硬件仿真／调试界面

网页版也支持“视图 → 硬件仿真”，点击后请求打开新的浏览器标签页，并沿用当前页面的服务地址及认证令牌。若浏览器拦截弹出页面，请允许本站打开新标签页后重试。网页通过桌面服务操作硬件，ST-Link、GDB 与目标单片机应连接或安装在运行该服务的电脑上。

网页与桌面共享调试会话、安装进度及设备互斥保护；可在网页选择本地 ELF／AXF 文件上传为符号文件（最大 128 MiB），再使用寄存器、反汇编、内存、断点和执行控制。指定本机 GDB 可执行文件仍在桌面窗口完成。关闭浏览器标签页不会主动断开共享会话；结束调试请点击“断开调试”。

从“视图 → 硬件仿真”打开独立窗口，选择 STM32 的 ST-Link 探针与 ELF 符号文件。调试需要 `st-util` 和 `arm-none-eabi-gdb`；可安装 GNU 工具或指定已有 GDB。

| 页面      | 显示内容                                                |
| --------- | ------------------------------------------------------- |
| 概览      | 连接状态、运行状态与 CPU 架构示意                       |
| CPU／指令 | 暂停时的寄存器、状态标志、PC 位置、反汇编、调用栈及断点 |
| 内存      | 暂停时按指定地址读取真实目标内存                        |
| 静态存储  | 本地 ELF 的装载段与文件字节预览                         |
| 日志      | 调试器输出及诊断信息                                    |

支持继续、暂停、单步等操作。运行时保留最后一次暂停采样，并显示采样时间；架构示意不代表逐周期虚拟仿真。本地 ELF 预览也不等于目标 Flash 回读。

连接调试不会自动下载固件。调试占用 SWD 期间，识别和烧录受互斥保护；结束会话释放连接。

## 工具安装输出与警告

首选项顶部显示工具安装输出。点击安装后立即显示准备状态，再显示下载、校验、解压、安装及成功或失败结果；第三方安装程序的输出也会实时显示。独立调试窗口安装 GNU 时共用此进度显示。

下载总大小已知时显示实际字节量与百分比；总大小未知，或处于解压、安装等阶段时使用不定进度条。百分比表示当前下载文件的进度。查看较早日志时停止自动滚动，回到底部继续跟随；本次应用运行期间重新打开首选项可看到最近安装任务。

底部“问题”旁增加“警告”。需要选择端口、保存修改等前置条件提示进入警告列表，便于与编译错误区分。

底部“输出／串口监视／问题／警告”作为一个整体面板，可点击右上角叉号一起关闭，从“视图 → 显示底部面板”重新打开。编译开始时会自动显示输出面板；关闭面板不清空日志，也不主动断开串口连接。

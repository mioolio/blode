# 工程 ZIP 分享

## 使用流程

1. 打开工程，从“文件 → 打包工程”进入预览。
2. 核对文件数量、源码大小、外部依赖和工具版本要求。
3. 若存在工程外依赖，确认将这些文件复制进归档。若存在无法自动迁移的引用，先修复，或明确选择带警告导出。
4. 导出标准 ZIP。桌面端选择保存位置；网页端下载到浏览器。
5. 接收者解压后打开归档中的工程目录，安装或选择匹配工具版本，再编译。

打包前保存当前界面与已同步协作草稿。打包仅修改内存中的归档副本，原工程及外部依赖保持不变；不自动运行构建或烧录。

## 迁移策略

| 来源                                                  | 处理                                                                                             |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 工程内文件                                            | 保留相对目录                                                                                     |
| `be.build.entry/sketch/files`                         | 收集指定文件／目录并改写包内路径                                                                 |
| Keil `.uvprojx` 的 FilePath／IncludePath／ScatterFile | 收集文件与包含目录，改写副本中的路径                                                             |
| 可解析的 C/C++ `#include`                             | 收集被引用文件，将包内引用改为相对路径                                                           |
| 工程外依赖                                            | 复制到 `dependencies/<标识>-<目录名>/`，避免同名冲突                                             |
| 目标电脑的工具绝对路径                                | 从副本配置中移除；记录已知版本要求，接收者重新选择                                               |
| `be.build.settings` 各层工具选择                      | 保留模式、体积优化、工具系列与版本；移除本机绝对 `directory`、`arduinoCli` 和 `packageDirectory` |

归档附 `.blode-share/manifest.json`，包含文件大小、SHA-256、外部依赖标记、工具要求和迁移警告。`portable` 仅表示本次扫描未产生已知警告，并不代替在另一台电脑编译验证。

工具要求包括已识别的 `gnu-arm:<版本>`、`arduino-cli:<版本>`、`arduino-esp32:<版本>`，以及通用／平台／语言层的编译器选择。自定义路径以配置位置标记，不把主机绝对工具路径写入归档副本。接收者通过[编译设置](PROJECTS.md)选择自己的已安装工具；只保留系列与版本时会查找本机匹配的已安装工具，包括并行版本目录。分享包不包含编译器，打开工程不触发工具下载。

## 排除与边界

默认排除 `.git`、依赖安装目录、工具链、构建缓存、既有分享元数据及常见私密环境配置（例如 `.env`、`.npmrc`、`.ssh`）；`.env.example/sample/template` 可保留。不会复制 Git 历史或主机已保存的 Git 凭据；其他自定义源码配置仍应由分享者审查。

符号链接不递归跟随。宏生成的 include、自定义构建变量、找不到的引用和不能确定的绝对构建路径会产生警告。CMake／Make 自定义构建脚本尚不支持通用路径迁移。GNU／SDK 自带系统头文件和库仍由相应工具链提供，不复制编译器二进制；Arm Compiler 6 等受许可约束的工具需接收者自行配置。

当前限单文件 64 MiB、源码总量 256 MiB、约 9990 个文件、目录深度 24；不使用 ZIP64。导出列表有界，过期下载 ID 需重新生成。文件存在未同步冲突时会先提示，不静默覆盖协作者内容。

## 验证范围

Windows 临时工程测试覆盖标准 ZIP 结构、CRC／解压、外部头文件与 Keil 路径重写、各层编译设置的 Windows／UNC／POSIX 绝对路径清理、工具要求记录、源文件保持不变、警告和容量边界。跨电脑真实工具链构建、Linux 解压与编译仍待验证，见 [路线图](ROADMAP.md)。

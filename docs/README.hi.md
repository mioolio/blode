# Blode Studio

[简体中文](../README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [العربية](README.ar.md) · **हिन्दी**

Blode Studio एक मॉड्यूलर एम्बेडेड विकास कार्यस्थल है। इसमें कोड संपादन, फ़र्मवेयर बिल्ड और फ़्लैशिंग, सीरियल संचार, हार्डवेयर डीबगिंग, Git और टीम सहयोग शामिल हैं। Electron डेस्कटॉप ऐप इस्तेमाल करें या प्रोजेक्ट और हार्डवेयर वाले कंप्यूटर पर Node.js होस्ट चलाकर ब्राउज़र से जुड़ें।

[GitHub Releases](https://github.com/mioolio/blode/releases) · [CHANGELOG](../CHANGELOG.md) · [Issues](https://github.com/mioolio/blode/issues)

## उपलब्ध सुविधाएँ

- clangd से C/C++ पूर्णता, परिभाषाएँ, संदर्भ, निदान और फ़ॉर्मैटिंग; विकल्प के रूप में कार्यक्षेत्र इंडेक्स। पूर्वावलोकन टैब, विभाजित संपादन और ड्राफ़्ट पुनर्प्राप्ति।
- डिवाइस जोड़े बिना बिल्ड करें। नाम वाले बिल्ड प्रवेश-बिंदु, Debug/Release, आकार अनुकूलन और C/C++ के लिए अलग टूलचेन चयन।
- BIN, HEX, S-record और ELF निर्यात, तैयार फ़र्मवेयर की फ़्लैशिंग और बाहरी स्रोत निर्भरताओं सहित प्रोजेक्ट साझा करना।
- Arduino लाइब्रेरी खोजें, घटक फ़ोल्डर या ZIP आयात करें और ऑफ़लाइन उपयोग के लिए डिवाइस मॉड्यूल व टूलचेन निर्यात करें।
- रजिस्टर, डिसअसेंबली, कॉल स्टैक और मेमोरी देखें; जुड़े लक्ष्य पर एक-एक चरण चलाएँ और एक साथ कई ब्रेकपॉइंट जोड़ें।
- टैब, संपादन क्षेत्र और नवीनतम लॉग साझा करें। स्वतंत्र बदलाव मिलाएँ और टकराव सुरक्षित रखें। ब्राउज़र का पूर्ववत आदेश केवल उपयोगकर्ता के अपने बदलावों पर लागू होता है।
- Git इतिहास, अंतर, स्टेजिंग, कमिट, शाखाओं और रिमोट का ग्राफ़िकल प्रबंधन; कई मूल टर्मिनल सत्र और VS Code कनेक्शन।
- चित्र पूर्वावलोकन और ऑडियो/वीडियो प्लेबैक; वैकल्पिक AI पूर्णता और चुने हुए दायरे में प्रश्न व संपादन। मॉड्यूल और एक्सटेंशन अपने संसाधन और भाषा सूची रखते हैं।

## समर्थित हार्डवेयर और होस्ट

| डिवाइस मॉड्यूल                   | बिल्ड उपकरण                      | कनेक्शन             |
| -------------------------------- | -------------------------------- | ------------------- |
| Esp32_S3_CAM · ESP32-S3          | Arduino CLI + Arduino-ESP32      | UART / USB-JTAG     |
| STM32F103C8T6 · STM32F103C8/C8T6 | GNU Arm GCC / Arm Compiler 5 / 6 | ST-Link / SWD / GDB |

वर्तमान प्रोफ़ाइल ESP32-S3 और STM32F103C8/C8T6 को कवर करती हैं। कैमरा पिन प्रोजेक्ट में निर्धारित होते हैं। ESP32-S3 UART GDB को Windows संदर्भ सेटअप पर जाँचा गया है; मूल USB-JTAG का सत्यापन जारी है। Windows x64 मुख्य वितरण है। Linux x64/ARM64 अनुकूलन और macOS के कस्टम टूल पथ का वास्तविक मशीनों पर पूर्ण सत्यापन बाकी है।

## त्वरित शुरुआत

स्रोत से विकास के लिए Node.js 24+, npm और Git चाहिए।

```sh
git clone --single-branch https://github.com/mioolio/blode.git
cd blode
npm ci
npm run dev
```

ब्राउज़र कार्यस्थल के लिए नीचे के आदेश प्रोजेक्ट और हार्डवेयर वाले कंप्यूटर पर चलाएँ और दिखाई गई लिंक खोलें। फ़ोल्डर चयन, बिल्ड, USB, सीरियल पोर्ट और टर्मिनल उसी होस्ट कंप्यूटर पर काम करते हैं।

```sh
npm run web:build
npm run web:start
```

## मॉड्यूल संरचना और बाइनरी होस्ट

डिवाइस मॉड्यूल दस ज़िम्मेदारियों में विभाजित हैं: `support`, `device`, `runtime`, `constraints`, `ui`, `compiler`, `debugger`, `layout`, `languages` और `tools`। `be` बिल्ड इनपुट तथा `blode.components.json` प्रोजेक्ट लाइब्रेरी दर्ज करता है। `package:runtime` स्वतंत्र JavaScript, मैनिफ़ेस्ट और संसाधन बनाता है, जिन्हें संगत बाइनरी ऐप और Web होस्ट अपने TypeScript स्रोत के बिना लोड करते हैं। सामान्य एक्सटेंशन कंपाइलर बनाए बिना रूप, मेनू, विंडो और निचले पैनल जोड़ सकते हैं।

```sh
npm run package:runtime -- extensions/boards/Esp32_S3_CAM --output ./release/modules --zip
```

## पैकेज हस्ताक्षर

- `obe`, Ed25519 से हस्ताक्षरित JSON मैनिफ़ेस्ट है। यह प्रकाशक, पैकेज ID/संस्करण और प्रत्येक फ़ाइल के पथ, आकार तथा SHA-256 को जोड़ता है। स्थापित करने से पहले वास्तविक सामग्री फिर जाँची जाती है।
- आधिकारिक भरोसा होस्ट की सार्वजनिक कुंजी सूची से आता है। बिना हस्ताक्षर या अज्ञात प्रकाशक, खराब हस्ताक्षर और बदली सामग्री अलग पहचाने जाते हैं। निर्यात मौजूदा हस्ताक्षर बचाता है, किसी बाहरी पैकेज को आधिकारिक पहचान नहीं देता।
- निजी कुंजियाँ `.signing/` में रहती हैं और Git तथा वितरण पैकेजों से बाहर हैं। Windows Authenticode अलग स्तर है; वर्तमान प्रमाणपत्र स्व-हस्ताक्षरित है, सार्वजनिक CA द्वारा जारी नहीं। हस्ताक्षरित सामग्री बदलने पर दोबारा हस्ताक्षर करना होता है।

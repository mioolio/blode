# 工作台交互更新

状态：内部开发预览，基于 0.2.3.6。分支为 `codex/runtime-plugins-internal`，继续使用 `0.2.3.6-internal` 显示版本。本次更新源码，不生成新的正式发行包。

## 升级与启动

拉取分支后运行 `npm ci`，然后使用 `npm run dev` 启动桌面版。独立 Web 宿主使用 `npm run web:build` 和 `npm run web:start`。

本次新增 `node-pty`、`@xterm/xterm` 和 `@xterm/addon-fit`。终端前端按需加载，进入首页不会启动 PowerShell。桌面打包将原生 PTY 文件保留在 ASAR 外；Web 包的运行依赖也包含 `node-pty`。

## 交互终端与编码

**终端 → 命令窗口** 打开持久 Shell。Windows 优先使用已安装的 PowerShell 7，否则使用系统 Windows PowerShell 5.1，通过 ConPTY 提供原生终端交互。`cd`、变量、命令历史、Tab 补全、交互式输入和窗口尺寸在同一会话中持续生效。Ctrl+C 中断前台命令并保留会话；选中文本时 Ctrl+C 复制。关闭终端结束该 Shell，隐藏底部面板保留它；点击右上角 **新建终端** 可再次建立会话。

终端共享同一个目标机器会话。多个客户端同时打开终端时会操作同一个 Shell，输入和输出相互可见。切换工程前须先中断或关闭仍在运行的命令；空闲会话会按新工程目录重新建立。

PowerShell 初始化控制台和管道 UTF-8。编译等外部进程的 stdout、stderr 分别解码，支持跨缓冲区的 UTF-8、Windows GB18030 及带 BOM 的 UTF-16。PTY 的 ANSI 数据原样交给终端；AI 的文本快照另外清理转义控制序列。

自动化新增 `terminal.open`、`terminal.write`、`terminal.resize`、`terminal.close`；状态读取支持会话与序号游标。创建、输入和关闭会话需要明确的 `confirm: true`。完整接口见 [AI 控制指南](../AI-PIPE.md)。

## 退出与托盘

- 没有未保存内容时，关闭主窗口直接退出。
- 文件、工程配置或协作者共享文档未保存时，提供 **保存并关闭／放弃并关闭／取消**。
- 保存失败、存在冲突或保存期间有新修改时，窗口保留；最终退出前冻结共享写入并重新检查保存状态。
- **首选项 → 常规设置 → 关闭时最小化到托盘** 默认关闭。启用后点击叉号收起，点击托盘图标恢复，右键 **退出** 执行保存检查。
- Web 标签关闭或刷新使用浏览器原生未保存提醒。三选项退出框只用于桌面；浏览器关闭标签不结束宿主服务。

关闭事务、超时及配置存储细节见 [窗口与托盘说明](desktop-lifecycle.md)。

## 插件视图

插件在 `manifest.json` 的 `ui.views` 中注册视图，指定 `id`、`label`、包内 HTML 文件和 `window`／`panel` 位置。在 **视图 → 扩展视图** 打开，也可通过原生 SDK 的 `host.openView(id)` 或 HTML 内的 `window.blodeRuntime.openView(id)` 请求打开。

桌面独立窗口复用同一插件的同一视图，关闭后可以重开。Web 使用新的浏览器标签；没有点击手势的请求先显示打开入口，由用户点击。面板视图加入底部输出、串口等标签旁，整体关闭和恢复行为相同。HTML 内容可由作者自行编写，窗口大小可在声明中指定。

所有入口共用声明、包路径和授权检查。独立窗口仅暴露所属插件的接口，HTML 仍在独立文档及隔离 iframe 中运行。字段示例和 SDK 契约见 [运行时插件开发指南](../RUNTIME-PLUGINS.md)。

## 协作注意力与恢复

页面隐藏、失焦、最小化、锁屏、挂起或断线后，不显示为正在阅读／编辑代码。后台保留已打开标签的所有权，不复活用户已关闭的共享建议。回到前台时先重新获取工作区和共享文档，保留本地脏稿，再发布当前文件、光标和视口。

浏览器和桌面共用注意力注册器，新增来源可独立注册。桌面额外接收主进程窗口与电源事件；私有代次握手过滤导航前排队的请求和迟到回复。在线心跳仍用于连接维护，不触发硬件探测。用户未移动鼠标但正在阅读时，不按空闲计时器误判离开。

协议与标签规则见 [多人协作](../COLLABORATION.md)。

## 界面细节

保持现有布局与配色，集中调整信息层级：硬件调试去掉重复 PC/SP 卡片、重复寄存器区域和“数据来源”等说明；保留连接、执行、符号、断点与错误。首选项移除总括性副标题，驱动安装和授权细节通过 **安装说明** 查看。设备面板隐藏滚动条，滚轮、触控板和键盘仍可滚动。复选框、焦点样式及明暗主题保持一致。

文案审查范围见 [UI 文案审查](ui-copy-audit.md)。设计审查参考 [Anthropic frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)、[Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) 和 [VS Code Panel UX](https://code.visualstudio.com/api/ux-guidelines/panel)，未安装额外技能。

## 验证与平台

2026-10-30 最终验证：`npm test` **430 项通过，零失败、零跳过**；`npm run build`、`npm run web:build` 和格式检查通过。Web 宿主通过 Electron 导入排除检查，Node CLI 帮助显示内部版本。

Windows 已使用实际 PowerShell 7、Windows PowerShell 5.1 与 Electron Node 运行时验证 PTY 加载、中文目录／变量、交互输入、持久会话、缩放、中断和清理。额外覆盖连续静默／有输出命令、立即中断、ConPTY 完成标记与屏幕数据两种到达顺序，测试历史使用隔离目录。服务测试覆盖注意力代次、断线／恢复、退出冻结、保存失败、托盘生命周期、插件视图路径与窗口复用。

Linux 路径使用系统 Shell 与 PTY，但此次未在 Linux 实机执行。`node-pty` 在 Linux 需要 Python、make 和 C/C++ 编译工具，运行 `npm ci` 前安装这些系统依赖；USB 权限和桌面托盘行为另需实机验收。

本轮没有将自动化模型测试标为真实界面验收。桌面托盘点击、浏览器弹窗、终端键盘交互以及物理硬件调试的组合操作仍需用户验收。

### 人工验收清单

1. 打开命令窗口，执行中文 `Read-Host`、`cd`、变量赋值、Tab 补全和 Ctrl+C；隐藏再打开，确认会话保留。
2. 分别关闭干净工程、未保存文件、未保存配置和存在协作者草稿的主窗口，验证保存、放弃、取消及失败后的继续编辑。
3. 启用托盘，点击叉号、恢复、右键退出；退出前再制造一个未保存文件。
4. 使用两台客户端切换标签和后台、刷新、断网及恢复，确认头像与选区消失／恢复，关闭过的建议标签保持关闭，脏稿仍在。
5. 使用已授权插件打开底部视图和独立窗口／浏览器标签，反复关闭重开；撤销授权后再次请求。
6. 检查硬件调试的连接、暂停、寄存器、内存、断点和错误提示，以及首选项安装说明的键盘关闭和焦点返回。

# Blode Studio 0.3.4.3

本次更新加入 clangd C/C++ 语言服务、工程资源树状态持久化，并修复打包资源与 STM32 调试问题。

## 新增

- 接入 clangd 23.1.0：C/C++ 补全、悬停、定义、引用、诊断、格式化、代码操作、文件大纲和工程符号搜索优先由宿主管理的 clangd 提供；未安装时回退到宿主内置语言服务。
- 完整安装包可内置 `tools/clangd/`（`npm run fetch:clangd`），轻量包在“首选项 → 工具链 → 版本”下载安装；版本、SHA-256 和 ZIP 解压均有校验。
- 资源树的文件夹展开／折叠状态保存到工程内 `.blode/explorer.json`，重新打开工程时恢复上次结尾的状态；根节点折叠也会记录，已删除目录的旧状态自动清理。
- 编辑器诊断同步到“问题／警告”页和状态栏，显示数量并可点击跳转；日志错误与编辑器标记分开来源、合并显示。
- 新增 `Ctrl+T` 工程符号搜索和 `Ctrl+Shift+O` 文件大纲。

## 编译数据库

- 优先复用实际构建生成的 `compile_commands.json`：Arduino CLI 在 `.blode/build/compile_commands.json` 写入完整参数，STM32 构建也写入同一位置。
- 没有构建数据库时，使用 `be` 构建入口、工作区递归包含目录和 STM32 板级构建模型；`.uvprojx` 只作为可选补充，缺失或损坏仍能工作。
- 不再由语言服务硬编码器件宏、目标或头文件预包含；换芯片、换工程不需要维护名称列表。

## 移除

- 删除内置 C/Arduino JSON 补全目录：`extensions/completions/C/*` 仅保留 `rules.json`，`extensions/completions/C++` 与板卡 `languages/C++` 补全数据移除。工程 `languages/C/<标准>/*.json`、`blode.completions.json` 与 AI 用户条目继续与 clangd 结果合并；诊断规则保留。

## 修复

- 修复 Keil／STM32 工程中 `#include "stm32f10x.h"`、`#include "Delay.h"` 被误报 `file not found`，以及缺少器件宏导致 `Please select first the target STM32F10x device` 的问题。
- clangd 诊断只对翻译单元（`.c`／`.cc`／`.cpp`／`.cxx`）发布；头文件和 `.ino` 依赖构建包含顺序、Arduino 预处理或目标 ABI，单独解析的误报不再写入“问题”页，完整错误以真实构建输出为准。
- 修复打包时出现 `ENOENT`、找不到 `AiWorkspace` 等界面资源的问题；桌面版和 Web 版使用独立构建目录。
- 修复 STM32 编译后调试选项不可用、状态查询反复等待，以及局域网访问开发版跳转到 `127.0.0.1` 的问题。
- 升级 node-pty 到 1.2.0-beta.18，修复 Windows ConPTY 全局句柄表在多终端并发创建／退出时的数据竞争和 `remove_pty_baton` 断言崩溃。

## 升级说明

- 保存工程并退出旧版本，重新打开工程；资源树状态从本次版本开始记录。
- 第一次构建后，STM32/Arduino 会生成新的 `.blode/build/compile_commands.json`，语言服务随后使用真实编译参数。
- 轻量包首次使用 C/C++ 语言服务时，需要安装 clangd。

## 下载

- **桌面便携版**：Windows x64，直接运行 EXE。
- **轻量 Web 版**：目标电脑安装 Node.js 24+，解压后执行 `npm ci --omit=dev` 和 `npm start`。

Linux 和 macOS 尚未完成实机验证。详细测试范围见 [clangd 语言服务](../CLANGD.md) 和 [内置语言服务](../LANGUAGE-SERVICE.md)。

# Blode Studio 0.3.4.3

本次更新修复打包资源丢失和 STM32 调试卡顿，改善局域网协作访问。

## 修复

- 修复打包时出现 `ENOENT`、找不到 `AiWorkspace` 等界面资源的问题。桌面版和 Web 版使用独立构建目录，避免开发服务或其他构建覆盖正在打包的文件。
- 修复 STM32 编译后调试选项不可用、状态查询反复等待的问题。
- 减少调试状态轮询中的重复 ELF 校验，提升调试界面的响应速度。
- 连接调试器时可以取消，取消后不会继续发起连接。
- 修复局域网访问开发版时跳转到 `127.0.0.1` 的问题。
- Windows 局域网防火墙规则支持当前子网，无需逐个配置客户端 IP。
- 修复便携版因文件完整性标签异常而无法写入临时目录的问题。

## 下载

- **桌面便携版**：Windows x64，直接运行 EXE。
- **轻量 Web 版**：目标电脑安装 Node.js 24+，解压后执行 `npm ci --omit=dev` 和 `npm start`。

升级前保存工程并退出旧版本。Linux 和 macOS 尚未完成实机验证。

# Blode Studio 0.3.5.2

发布日期：2026-10-31

本次更新完善设备模块与工具链管理，支持独立 ZIP 分享、离线导入，以及每次重新收集的工具链导出。

## 下载

| 版本           | 文件                                        | 使用方式                                                                     |
| -------------- | ------------------------------------------- | ---------------------------------------------------------------------------- |
| 桌面便携版     | `Blode.Studio-0.3.5.2-desktop-win-x64.exe`  | 直接运行，使用桌面工作台                                                     |
| Web 版         | `Blode.Studio-0.3.5.2-web-win-x64.exe`      | 在项目和硬件所在电脑运行，通过浏览器访问，无需安装 Node.js                   |
| Web Node.js 版 | `Blode.Studio-0.3.5.2-web-node-win-x64.zip` | 需 Node.js 24+ x64；解压后双击 `start-web.cmd`，或运行 `node launch-web.cjs` |

三个版本均面向 Windows x64，并附 SHA-256 校验文件。Web Node.js 版省去内置 Node 运行时，包含运行所需依赖，无需执行 `npm install`。编译工具可在首选项中安装，也可选择本机已有工具路径。

## 新增与改进

### 设备模块

- 在 **组件库 → 设备模块** 中统一管理 ESP32、STM32 和第三方模块，支持搜索、分页、加载 ZIP／文件夹、用于当前工程和导出 ZIP。
- 新模块加载后即时注册；桌面与 Web 构建包含独立设备模块，导出模块无需宿主源码。
- 编译设置只列出当前工程涉及的平台与工具，减少大量第三方模块对界面加载和选择的影响。

### 工具链与离线交付

- **首选项 → 编译与工具链** 管理版本、下载和离线导入；**工具链与导出** 展示本机实际识别到的工具、版本、路径与来源。
- 支持 GNU Arm、Arm Compiler、Arduino CLI、Arduino-ESP32、ST-Link 和 clangd 工具链的 ZIP 导出与离线导入。
- 工具链归档按类型收集可执行文件及其依赖；Arduino 工具链导入时重新生成目标电脑的路径配置。
- 每次导出重新检测工具、扫描源目录并计算文件哈希，生成新的清单和 ZIP，移除复用旧导出包的界面入口。

### 导出进度

- 分别显示导出、下载和安装状态，修复导出时显示“正在准备安装”以及重复阶段日志的问题。
- 日志展示扫描目录、当前文件、文件数、总大小、压缩引擎、进度、ZIP 大小、SHA-256 和耗时。
- 内置 7-Zip 26.05，附许可证和对应源码；不可用时自动切换到备用 ZIP 引擎。
- 文件进度限频更新，压缩与校验支持进度显示，取消任务会清理未完成的归档。

## 升级与使用

1. 退出旧版，运行对应的新版本文件。
2. 在组件库中管理设备模块，在首选项中管理工具链；两类 ZIP 分别导入。
3. 在 **生成 → 编译设置** 中为当前工程选择编译器、语言版本和优化选项。

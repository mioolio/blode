# Blode Studio 0.3.5.9

发布日期：2026-11-01

本次更新新增 STM32 Arm Compiler 5 支持、组件签名与完整性校验，精简编译设置，并修复组件目录打开和桌面托盘行为。

## 新增与改进

### 编译与工具链

- STM32 支持 Arm Compiler 5，包含完整版本识别、C99、C++03、旧式 ARM 内联汇编和 Keil 启动文件。
- 支持 Debug／Release、固件体积优化，以及 ELF、BIN、HEX 导出。
- AC5 工具链支持指定版本、本机目录选择、ZIP 导出及离线导入。
- 编译设置合并“通用默认”与当前平台，采用单页表单；移除组件库入口和平台侧栏。
- C／C++ 可分别指定工具；已有语言配置自动展开，第三方编译后端覆盖设置收纳到高级选项。

### 组件签名与状态

- 设备模块、扩展、源码组件和工具离线包安装时统一校验 `obe` 签名及文件 SHA-256。
- 设备模块移除“使用”按钮，以“正常／异常／危险”显示校验结果；切换页面或刷新时重新读取文件。
- 官方模块和 Personalization 示例附带签名；未知发布者、无效签名和内容改动分别处理。
- 导出 ZIP 保留已有签名，安装确认绑定当次文件内容。
- 修复“打开所在位置”未弹出资源管理器；桌面发行包中的设备模块使用可直接访问的独立目录。

### 桌面窗口与托盘

- 关闭主窗口默认隐藏到托盘，单击或双击图标恢复窗口。
- “文件 → 退出”和托盘“退出”结束程序；存在修改时提供保存、放弃或取消。
- 修复保存的关闭配置导致托盘缺失，以及最小化窗口恢复不完整的问题。

### 发行构建

- 修复 Web 独立版追加发行签名时失败的问题。
- 新增仓库根目录 `build-release.bat`：输入四段版本号后，自动更新版本、构建三种发行包并生成校验和及发行说明。
- 构建输出位于 `release/<版本号>/`；保留步骤日志，遇到失败停止，已有同名发行包不会被覆盖。
- 提供独立 SHA-256 文件、`SHA256SUMS` 汇总及 `release-manifest.json`。维护者配置签发身份时，同时生成 `.obe` 签名文件。

## 下载与运行

| 版本           | 文件                                        | 使用方式                                                   |
| -------------- | ------------------------------------------- | ---------------------------------------------------------- |
| 桌面便携版     | `Blode.Studio-0.3.5.9-desktop-win-x64.exe`  | Windows x64，直接运行                                      |
| Web 独立版     | `Blode.Studio-0.3.5.9-web-win-x64.exe`      | 在项目和硬件所在电脑运行，通过浏览器使用；无需安装 Node.js |
| Web Node.js 版 | `Blode.Studio-0.3.5.9-web-node-win-x64.zip` | 需 Node.js 24+ x64；完整解压后运行 `start-web.cmd`         |

Web Node.js ZIP 已包含运行依赖，无需 `npm install`。编译器按需安装，或选择目标电脑上的已有工具。三个发行包均不附带 AC5 工具和本机许可证。

## 升级与验证

退出旧版后启动新版本。桌面端请使用文件菜单或托盘菜单退出，再替换旧文件。

相关测试覆盖签名与内容改动、模块分享、托盘关闭与退出、工具链选择及 AC5 编译。Windows 原生托盘和本机 AC5 参考编译已验证；发行构建包含类型检查、桌面渲染资源检查与 Web 版本检查。本次发行面向 Windows x64，Linux／macOS 发行包及跨机器硬件操作尚未验证。

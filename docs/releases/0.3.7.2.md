# Blode Studio 0.3.7.2

发布日期：2026-11-02

## 更新内容

- 新增 STM 自定义、ESP 自定义模块，提供型号、地址、容量、Arduino FQBN 和外部构建程序参数；支持无工程固件烧录与模块 ZIP 分享。
- 启动时隐藏底部面板，编译时自动展开，仍可从视图菜单打开。
- 修复资源布局缩容越界、删除后的选中状态、拖动回到起点与取消拖动；改善数值输入和新增区域操作。
- 更新 esbuild 至 0.28.2、minimatch 引擎至 11.0.3，保留旧版打包依赖需要的 API 兼容层。

- 移除目标设备面板里的重复组件库入口；组件管理仍从扩展菜单打开。
- 编译警告与错误接入底部诊断列表和计数，支持点击文件行列定位、代码行颜色及编辑器标记；映射 Arduino 临时草图、组件源码和命名子工程到原工程文件。
- 最新编译的诊断独立保留，避免详细输出刷掉较早警告；桌面与 Web 复用同一结构化结果，重新编译和清空后移除旧标记。见[编译诊断](docs/COMPILER-DIAGNOSTICS.md)。

- AI 助手改为自适应输入底框，范围、提问／修改、引用添加与模型设置集中在底部；引用支持行号、预览、移除、工程文件搜索和会话回看。
- 发送固定使用显示的引用快照，修复编辑器改变选区后发送内容与引用不一致的问题；附加文件不会扩大代码修改范围。
- 预测补全增加语言、近期编辑、文件头及直接引用的工程头文件上下文，保留匹配输入后的剩余建议，及时取消偏离输入或协作更新后的旧建议。
- 新增 Agnes AI 配置预设；使用官方 Chat Completions 接口和 `agnes-2.5-flash`，密钥仅保存在宿主凭据存储中。验证详情见 [AI 服务与补全](docs/AI-COMPLETIONS.md)。

以下改动已进入 `main`，尚未重新生成 0.3.5.9 的现有发行包。当前实现、构建与实机验证见[状态总览](docs/STATUS.md)。

- 修复 ST-Link 1.9.0 安装状态被写死为未安装、Windows 版本缺少下载与安装操作的问题；接入官方 Windows ZIP 下载、校验、安装及离线导入。
- 统一 ST-Link 设备识别、工具清单和调试服务的路径发现，支持托管目录、`versions/stlink/<版本>`、自定义包根目录／`bin` 与 PATH。
- 同时检查 `st-info`、`st-flash` 的退出码与版本，修复旧版本掩盖新版本、导入后仍不可识别的情况；导出保留依赖 DLL 和芯片定义。
- 2026-11-01：55 项相关回归与类型检查通过，独立模块构建通过；真实工具导出／隔离导入后识别 STM32F1 成功，本轮未烧录或启动 GDB 会话。
- 按当前源码校正文档的菜单入口、设备模块状态、驱动与工具区别、托盘默认行为、三种发行方式和平台验收范围；更新 13 份 README 的当前状态。

- 新增 13 种界面语言的统一注册、系统语言识别、偏好保存、按需加载、英语回退和同源窗口同步；编辑器常用右键菜单及托盘一起切换。
- 阿拉伯语界面增加 RTL 方向，源码、终端和原始日志保持原阅读方向；官方 Personalization 扩展补齐独立语言清单。
- 增加项目首页 README 的 13 种语言介绍与语言导航，补充宿主与二进制模块、OBE／Windows 签名及发行流水线说明。

## 下载与运行

| 版本 | 文件 | 运行要求 |
| --- | --- | --- |
| 桌面便携版 | `Blode.Studio-0.3.7.2-desktop-win-x64.exe` | Windows x64，直接运行 |
| Web 独立版 | `Blode.Studio-0.3.7.2-web-win-x64.exe` | Windows x64，运行后在浏览器使用，无需安装 Node.js |
| Web Node.js 版 | `Blode.Studio-0.3.7.2-web-node-win-x64.zip` | Windows x64、Node.js 24+ x64；解压后运行 `start-web.cmd` |

Web 版在项目和硬件所在电脑启动服务。Node.js ZIP 已包含依赖，无需 npm install。编译工具在首选项中安装，或选择本机已有工具。

三个发行包均提供 SHA-256 校验文件。本次未构建 Linux、macOS 发行包。

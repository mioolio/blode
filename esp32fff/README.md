# ESP32-S3-CAM 摄像头调校台

## 当前热异常与单次弱光测试

用户报告摄像头小板曾升至约 95℃并造成手部起泡。网页服务已停止；在排查硬件前，不恢复连续预览。软件待机和关闭 XCLK 不能代替物理断电，也没有提供温度测量或过温保护。

新增 `night_capture.py`：从关闭状态直接执行一次 `SNAPNIGHT`，640×480，单缓冲；先复制 JPEG，再写入并读回 OV5640 软件待机位，关闭 GPIO15 摄像头时钟、释放驱动，然后传输内存中的照片。主机拒绝未确认待机的结果，失败不自动重拍；结束后复位回摄像头关闭状态。

2026-10-26 的实际记录：`photos/night-test-20261026-204742.jpg`，采集流程 1975ms，`standby_verified=1`、`clock_low=1`，传输 CRC32 `c7ec0099`；图像近乎全黑。拍摄前用户确认设备已冷却且放在绝缘耐热表面；红外补光条件未确认，不能据此判断红外夜视能力。测试未测量温度。

固件还提供 `STANDBY` 命令；7秒软件定时器仅作为采集超时后关闭时钟并重启的后备机制，不是硬性时限或热保护。其他旧命令仍可能持续启用摄像头。

## 网页调参

打开 http://127.0.0.1:8765/ 即可查看预览，调整白平衡、RGB 增益、镜头校正、曝光和降噪，并拍摄、下载 **2592×1944** 或 2048×1536 原图。

预览提供「流畅」（320×240 / JPEG 24）、「均衡」（640×480 / JPEG 18）和「清晰」（800×600 / JPEG 10）模式，也可分别调整预览与照片的 JPEG 压缩值；数值越低画质越高、文件越大。照片默认使用 2592×1944、JPEG 10，预览模式不会降低照片的分辨率。

2026-10-26 实机测试：流畅模式连续 20 帧 CRC 校验通过，串口端平均 12.03fps；均衡模式连续 10 帧通过，平均 2.61fps。网页实际显示帧率还包含请求和解码耗时，光线及画面细节也会影响结果。原先同等 VGA/JPEG 12 的串口速度约 1.3fps，优化后约 1.66fps；网页已移除每帧额外 160ms 的等待。

当前 CH340 链路保留验证稳定的 460800 波特率；921600、1M、1.5M、2M 实测均出现 JPEG CRC 错误。基准记录位于 `diagnostics/`，优化前代码和参数快照位于 `backup/before-performance/`。

完整 5MP 实拍：`photos/full5mp-2592x1944.jpg`。实际 JPEG 解码尺寸为 2592×1944，CRC32 为 `76e9ce82`，不是对旧图放大。

以后需要重新启动时，双击本目录的 `Open-Camera-Console.cmd`。启动器会在后台运行本机服务并打开浏览器；开发板保持 USB 连接即可。如果串口变化，在网页顶部选择新端口后连接。

滑块会自动应用；「保存参数」将当前设置保存在本机 `web-settings.json`，下次连接自动加载。「还原默认」恢复摄像头默认参数；再次保存可替换先前保存的设置。

房间灯光偏色时，可选「手动 RGB 增益」并用白纸作参照。局部偏紫时可比较「镜头校正」开关；网页上的效果直接来自摄像头。

网页服务使用串口期间，如需使用下方命令行拍照或重新烧录，请先在网页点击「断开连接」。

网页前端：`web/index.html`；本机服务：`web_console.py`；后台启动器：`launch_console.py`。服务仅监听这台电脑的 127.0.0.1。

## 串口拍照

开发板已经烧录 SerialCamera 固件，通过 CH340 / COM3 传回 JPEG，不需要 Wi-Fi。

实机检测：ESP32-S3 v0.2、16MB Flash、8MB Octal PSRAM。摄像头返回 PID `0x5640`，对应 OV5640，与原商品描述的 OV3660 不同。已验证 EYE 摄像头引脚配置及 2592×1944 JPEG 图片。

成功照片：`photos/photo-20261026-retry.jpg`（483512 字节，CRC32 `c0824338`），已解码并检查可辨认的真实场景。前两张测试照片拍摄时摄像头掉落，画面模糊。

## 再拍一张

保持开发板连接，在 PowerShell 中运行：

```powershell
python '.\capture.py' --port COM3 --resolution FULL5MP --quality 10 --reset
```

照片及校验日志自动保存到本目录的 `photos` 文件夹。默认分辨率为 2592×1944；此命令行脚本使用保守串口速率，传输会比网页慢。也可以运行 `Take-Photo.ps1`；端口变化时传入 `-Port COM4` 等实际端口。

接收程序校验长度、CRC32、JPEG 起止标记，并使用 Pillow 解码检查尺寸。

- 官方工具链及编译脚本：上级目录 `.tools/arduino/`

编译设置：Arduino ESP32 2.0.17；ESP32S3 Dev Module；OPI PSRAM；16MB Flash；USB CDC 关闭；`app3M_fat9M_16MB` 分区。

当前构建选择 `FlashMode=qio`，Arduino 定义的烧录参数实际是 `--flash-mode dio`：ROM 先以 DIO 读取引导程序，再由引导程序配置 Flash。手动使用 esptool 时须遵循这一参数。
